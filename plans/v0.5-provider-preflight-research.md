# SpanVouch v0.5 Provider Preflight Research

**Checked:** 2026-07-31 (Asia/Shanghai)

**Scope:** Public, first-party Alibaba Cloud Model Studio documentation only. No credential value or account data was read.

**Decision:** The user explicitly approved `qwen3.7-plus` for B4/B5 after reviewing this preflight.

## Findings

1. Alibaba Cloud's current Model Studio model catalog redirects to `https://help.aliyun.com/zh/model-studio/models`. The retrieved catalog lists `qwen3.7-flash`, `qwen3.7-plus`, and `qwen3.7-max`. It does not list `qwen3-14b` in the retrieved page. This proves only that `qwen3-14b` is absent from the public catalog snapshot; account-specific availability must still be checked after credentials are configured.
2. The same official catalog gives workspace-specific, regional OpenAI-compatible API roots such as `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`. Therefore the checked-in hash of `https://dashscope.aliyuncs.com/compatible-mode/v1` cannot authorize the current workspace endpoint.
3. Alibaba Cloud's official OpenAI compatibility documentation uses `DASHSCOPE_API_KEY` and a workspace-specific regional `/compatible-mode/v1` Base URL. SpanVouch may continue to expose the application-specific name `SPANVOUCH_QWEN_API_KEY`, but the runtime value and normalized URL hash must be bound to the selected workspace before a paid manifest is approved.
4. `https://www.alibabacloud.com/help/en/model-studio/pricing` currently resolves to an Alibaba Cloud 404 page. The model catalog itself is titled as a model specification and pricing page, so it is the current first-party source to capture when canonical pricing is frozen.
5. The local shell currently has no DeepSeek key, Qwen key, Qwen Base URL, or provider pricing paths configured. The checked-in pilot provenance still uses `pricing.example.invalid` for both providers. Existing fail-closed composition rejects a paid run until matching canonical pricing files are provided.

## Recommendation

Use `qwen3.7-plus` for B4/B5 if it is available in the user's Model Studio workspace. It is the balanced current Qwen tier between `flash` and `max`, which fits a verifier study better than optimizing only for lowest cost or maximum model capability. The material preregistration change from `qwen3-14b` has now received explicit approval.

Alternative choices:

- `qwen3.7-max`: strongest current listed Qwen tier, with higher expected experiment cost and a larger capability gap from the generator.
- `qwen3.7-flash`: lowest-latency/cost-oriented listed tier, with greater risk that verifier weakness dominates the comparison.

## Required Inputs Before Paid Preflight

- explicit approval of the exact Qwen model identifier;
- Alibaba Cloud Model Studio workspace region and OpenAI-compatible Base URL;
- Qwen API key supplied only through local environment configuration;
- canonical Qwen pricing JSON captured from the official model catalog for that region/model;
- canonical DeepSeek pricing JSON from the official DeepSeek source;
- a fresh pilot configuration hash and manifest authorization after all provenance values are frozen.
